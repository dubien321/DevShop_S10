DevShop - Boutique en ligne

Description

DevShop est une boutique en ligne développée avec HTML, CSS et JavaScript.

L'objectif du projet est de créer une interface de commerce électronique permettant à l'utilisateur de consulter des produits, de rechercher des articles, de filtrer les produits et de gérer un panier.

Fonctionnalités

- Affichage dynamique des produits
- Récupération des produits depuis une API
- Recherche d'un produit
- Filtrage par catégorie
- Affichage des informations des produits
- Affichage des évaluations avec des étoiles
- Formatage des prix en FCFA
- Ajout des produits au panier
- Affichage du nombre d'articles dans le panier
- Affichage du montant total du panier
- Suppression d'un article du panier
- Possibilité de vider le panier
- Navigation entre les produits avec les boutons Précédent et Suivant
- Interface responsive

Technologies utilisées

- HTML5
- CSS3
- JavaScript
- DOM
- Fetch API
- API REST
- LocalStorage
